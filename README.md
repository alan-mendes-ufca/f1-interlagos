# F1 Interlagos

Jogo de corrida de Fórmula 1 em primeira pessoa no Autódromo José Carlos Pace (Interlagos, São Paulo).

- Estrada pseudo-3D (estilo Top Gear/OutRun) em Canvas 2D puro, sem WebGL.
- Pixel art procedural na linha visual de Detetive 2D e Fauna Brasil: entardecer azul e ciano, luzes âmbar, acentos carmim e glow em canvas sobreposto.
- Corrida de 3 voltas contra 5 rivais fictícios.

## Rodar

```sh
npm install
npm run dev
```

Controles: setas ou WASD para guiar, Espaço para freio extra, Enter para começar/reiniciar.

## Fluxo de trabalho

GitHub flow: a `main` é protegida, toda mudança entra por branch e pull request com os checks **Lint** e **Tests** verdes.
